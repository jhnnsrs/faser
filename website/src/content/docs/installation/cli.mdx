In this guide, we will walk you through the process of installing faser as a CLI tool.

<Aside type="tip" title="Who is this guide for?"> 

Using the CLI is really just something for advanced users that want to automate or integrate 
faser into larger simulations.

</Aside>

<Steps>

1. ##### Create a python environment

    Using a tool like `conda, poetry or uv` (use uv, it's the best), create a virtual environment

2. ##### Install faser

    install Faser using

    ```bash
    pip install "faser[cli]"
    ```

</Steps>
